# Учёт Лочари

Готовое локальное веб-приложение для небольшой пекарни. Работает на компьютере и телефоне в одной Wi-Fi сети.

## Возможности

Вход OWNER / WORKER, дашборд, продукция, рецептуры, сырьё, производство с автоматическим списанием, готовая продукция, клиенты, отгрузки, оплаты, долги, расходы, отчёты и мобильный экран экспедитора. Бонусные баллы CRM заложены в данные.

## Запуск на Windows

1. Установите Node.js LTS с https://nodejs.org/
2. Откройте PowerShell в папке проекта.
3. Выполните по очереди:

    corepack enable
    pnpm install
    Copy-Item .env.example .env
    pnpm setup
    pnpm dev

4. Откройте http://localhost:3000

Для телефона в той же Wi-Fi сети: pnpm dev --hostname 0.0.0.0. Узнайте IP компьютера через ipconfig и откройте http://IP-КОМПЬЮТЕРА:3000.

## Тестовый вход

Владелец: owner / lochari2026
Сотрудник: worker / worker123
Супруга: wife / worker123

## Команды

pnpm dev — разработка
pnpm build — сборка
pnpm start — запуск сборки
pnpm db:seed — вернуть тестовые данные
pnpm db:reset — очистить базу и вернуть тестовые данные

База: prisma/dev.db. Для резервной копии остановите приложение и скопируйте файл.

## Новые разделы

- «Продукция» — редактирование цен, названий, артикулов и архив.
- «Клиенты» — редактирование карточек и архивирование.
- «Поставщики» — поставщики, многопозиционные закупки и автоматический приход сырья.
- «Команда» — сотрудники, роли, отключение доступа и смена паролей.
- В отгрузках кнопка «Печать» открывает накладную для принтера или сохранения в PDF.
- В разделе «Команда» владелец может скачать резервную копию базы.
- Отчёты показывают себестоимость проданного, валовую и чистую прибыль.

После восстановления резервной копии остановите сайт и замените файл prisma/dev.db скачанным файлом.
